# ShrimpGuard AI — Flutter Farmer App

Source-level foundation for the farmer mobile application.

## Important: platform folders are not included

This workspace did not have the Flutter SDK installed when the foundation was
created, so `android/`, `ios/`, and other platform folders were not generated.
The Dart source, `pubspec.yaml`, and app structure are complete.

After installing Flutter:

```bash
cd app/flutter_farmer_app
flutter create . --project-name shrimguard_farmer_app --platforms=android,ios,web
flutter pub get
flutter analyze
flutter run
```

Review the files generated by `flutter create .` before committing. It may add
or replace platform scaffolding, but the existing `lib/` structure should be
kept.

## API base URL

The default is the Android emulator loopback host:

```text
http://10.0.2.2:3000/api/v1
```

Override it at build time:

```bash
flutter run --dart-define=API_BASE_URL=http://<host>:3000/api/v1
```
